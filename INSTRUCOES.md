# 🚀 Instruções Rápidas - Investidor Master

## 📋 Comandos Principais

### 1. Instalar Dependências
```bash
npm install
```
*Instala todas as dependências do backend e frontend automaticamente*

### 2. Executar em Desenvolvimento
```bash
npm run dev
```
*Inicia backend e frontend simultaneamente com hot-reload*

### 3. Executar em Produção
```bash
npm start
```
*Inicia backend e frontend em modo produção*

### 4. Build do Frontend
```bash
npm run build
```
*Compila o frontend para produção*

## 🌐 Acessos

Após executar os comandos:
- **Frontend**: http://localhost:3000
- **Backend**: http://localhost:5000

## ⚠️ Pré-requisitos

- Node.js 14+ instalado
- npm ou yarn instalado
- Windows 10/11

## 🔧 Solução de Problemas

Se encontrar problemas:
1. Delete as pastas `node_modules` do backend e frontend
2. Execute `npm install` novamente
3. Verifique se as portas 3000 e 5000 estão livres
